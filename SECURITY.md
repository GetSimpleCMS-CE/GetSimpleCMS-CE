## Before Reporting a Vulnerability

Before submitting a security report, please check the latest **Dev/Beta version** of GetSimple CMS CE in the [main development branch](https://github.com/GetSimpleCMS-CE/GetSimpleCMS-CE/tree/main).

Some reported security issues may have already been identified and fixed in the latest development version but may not yet be included in a stable release.

Please verify that the issue still exists in the current development version before submitting a report. If it has already been fixed, please check whether the fix is included in a released version, as older stable releases may still be affected.
